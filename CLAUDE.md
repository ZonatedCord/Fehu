# Fehu — Project Notes for Claude

## Release process

### How to ship a new version

1. Make all commits to `main`
2. Bump version in **both** files:
   - `src-tauri/tauri.conf.json` → `"version": "X.Y.Z"`
   - `src-tauri/Cargo.toml` → `version = "X.Y.Z"`
3. Commit: `chore: bump vX.Y.Z`
4. Push main, then tag:
   ```
   git push origin main
   git tag vX.Y.Z
   git push origin vX.Y.Z
   ```
5. CI builds all platforms (~10 min) and auto-uploads artifacts + `latest.json`

### Moving an existing tag (hotfix mid-release)

```bash
git tag -d vX.Y.Z
git push origin :refs/tags/vX.Y.Z
git tag vX.Y.Z
git push origin vX.Y.Z
```

### latest.json

`latest.json` is required for the in-app updater (Tauri plugin-updater).
It is generated by the `create-update-manifest` job in `.github/workflows/release.yml`
after all build jobs finish. It reads `.sig` files from the release and builds the manifest.

**If the updater shows "Could not fetch a valid release JSON":**
- Check that `latest.json` exists in the GitHub release assets
- Check that the CI `create-update-manifest` job succeeded (it runs last)
- The script is at `.github/scripts/gen_latest_json.py`

The in-app updater only triggers if `latest.json` version > installed version.
Rebuilding the same version tag does NOT trigger an update prompt.

### CI workflow notes

- Workflow file: `.github/workflows/release.yml`
- 3 build jobs (aarch64-apple-darwin, x86_64-apple-darwin, windows) run in parallel
- `create-update-manifest` runs after all 3 succeed (`needs: build`)
- YAML heredocs with Python code cause parse errors → use external script instead
- TAURI_SIGNING_PRIVATE_KEY must be set as GitHub secret (key at `~/.tauri/fehu.key`)

## Telegram bot

- Script: `sidecar/fehu_bot.py` (aiogram 3, FSM-based)
- Bundled as Tauri resource in production: `tauri.conf.json` → `bundle.resources`
- Bot is auto-started on app launch if token is saved in settings
- Bot is killed on window close via `pkill -9 -f fehu_bot.py`
- If zombie processes accumulate: `pkill -f fehu_bot.py` in terminal
- Dep check validates aiogram 3+ FSM API (`from aiogram.fsm.context import FSMContext`)

## UI conventions

- No emoji anywhere in the UI — use lucide-svelte icons only
- All git tags, GitHub release notes, CI content must be in English
